# 小满食光点餐与管理系统架构设计 (ARCHITECTURE.md)

## 2. 订单生命周期与状态流转

### 2.1 状态码映射

| 状态码 (`order_status`) | 状态语义 | 触发动作 / 系统行为 |
|---|---|---|
| `101` | 待付款 (Created) | 提交订单后生成，超时默认设为 1440 分钟（24 小时）防止自提订单过早失效 |
| `201` | 已付款 (Paid) | 微信支付回调成功，或本地开发模拟付款（`mock_paid_order_*` 覆写）；**自动触发小票打印** |
| `301` | 制作中 / 配送中 (Shipped) | 商家发货；自动调用 `WxShippingService` 将物流或自提信息同步至微信发货管理接口 |
| `401` | 用户已提货 / 已确认收货 | 客户主动确认提货或收到外卖 |
| `402` | 系统自动确认收货 | 达到超时自动收货时限后自动流转 |
| `102` / `103` | 用户取消 / 系统取消 | 未支付取消 |
| `202` / `203` | 申请退款 / 已退款 | 售后退款流转 |

### 2.2 预约自提与结构化留言协议

预约自取信息统一在提交订单时拼装至 `message` 字段，并在多端通过 `orderParser.js` 统一解析：

* **拼装格式**：`[预约自取] 时间:<自取时间> | 称呼:<客户称呼> | 电话:<联系电话> | 备注:<客户需求>`
* **虚拟地址机制**：自提订单强制使用专属虚拟地址（姓名 `到店自提(小满食光)`，`areaCode` 为 `310115`），规避后端非空地址校验。
* **取餐号生成规则**：取订单号后 3 位取模拼接前缀，如 `A001` ~ `A999`。

## 3. 硬件与微信生态对接

### 3.1 飞鹅云打印机集成 (`LitemallPrinterClient`)

* **核心配置**：`litemall.printer.feieyun.appid` 与 `appsecret`。
* **自动打印触发点**：订单支付完成（状态变为 `201`）时由 `WxOrderService` 或后台确认触发。
* **打印模板规范**：
  * 顶部居中店名：“小满食光·手作三明治”
  * 醒目标注取餐号（自提）或配送标志（外卖）
  * 预约取餐时间、联系人与电话
  * 商品清单（品名、规格、单价、数量、小计）
  * 订单总金额与客户备注
  * 底部二维码/欢迎语
* **管理端操作**：支持后台列表增删改查打印机、在线状态探测、出纸测试与订单手动补打。

### 3.2 微信小程序发货信息管理 (`WxShippingService`)

* **对接微信官方发货 API**：`https://api.weixin.qq.com/wxa/sec/order/upload_shipping_info`
* **发货模式适配**：
  * `1` - 实体物流配送（顺丰、中通、圆通等主流快递，自动映射标准运力编码）
  * `2` - 同城配送（自送/同城骑手）
  * `3` - 虚拟商品
  * `4` - 用户自提（预约到店点餐模式专用）
* **接口安全与合规**：满足微信支付针对小程序交易合规的资金结算与订单物流追踪要求。

### 3.3 图片自动压缩与优化 (`StorageService` & `compress_images.py`)

* **后端自动压缩**：图片上传由 `StorageService` 拦截，通过 `Thumbnailator` 自动将超过 1280px 的大图等比压缩至合适分辨率，保留优质观感的同时大幅减小带宽占用。
* **离线批处理**：根目录 `./compress_images.py` 提供对已有图片资源的无损/微损批量处理，限定最大尺寸为 800px，压缩质量 85%。
