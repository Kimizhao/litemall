# 小程序内嵌商家工作台与移动端运营闭环

鉴于小满食光手作门店的日常运营（接单、出餐、自提核销、库存沽清、小票补打）高度依赖移动端，而原有桌面端管理后台（Vue 2 + Element-UI）在手机浏览器下操作繁琐、无法直接调起摄像头扫码且会话容易过期，系统决定直接在顾客端微信小程序（`xiaoman-wx-uniapp`）内嵌「商家工作台」。通过让店铺管理员账号（`xiaoman`）在小程序端首次验证后绑定当前微信号（OpenID），实现免密即时准入与状态保持；在操作层面上裁剪 PC 端冗杂的富文本大表单，针对餐饮实体店定制轻量化商品增删改查表单与订单核销流转，利用小程序原生 `uni.scanCode` 解决到店自提扫码核销痛点，并打通云端热敏小票补打能力。
