# 点单页售罄与低库存展示及聚合协议

为避免点单场景下已售罄餐品造成的误选与无效页面跳转，点单页（`pages/catalog/catalog`）实行全规格库存归零判定（`totalStock = sum(number) <= 0`）与售罄自动沉底策略。在视觉上弱化售罄卡片（`opacity: 0.6`）、右下角标注温暖灰褐色【已售罄】并拦截详情页跳转（原地轻提示）；对库存紧张餐品（$1 \le totalStock \le 3$）在简介下方打上陶土橙色【仅剩 X 份】微标。后端接口 `/wx/goods/list` 采用单次规格库存批量聚合，在返回的商品对象中透明扩展 `totalStock` 与 `isSoldOut` 字段，以规避移动端 N+1 请求并保证首屏性能。
