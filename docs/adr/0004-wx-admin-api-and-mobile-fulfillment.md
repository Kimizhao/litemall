# 微信小程序端商户专属接口规范与即时履约协议

为了在不侵入 PC 端后台既有权限拦截逻辑的前提下支持小程序内嵌商家工作台，系统在 `litemall-wx-api` 模块下独立开辟 `/wx/admin/...` 端点空间（涵盖订单、商品、类目、打印）。通过复用小程序既有的微信 Token 与用户会话，在拦截层校验微信号所绑定的店铺管理员身份及角色权限（Role ID 4，`xiaoman`）。

在履约流转上，订单状态机收敛为餐饮即时流转视图（待制作、待取餐、已完成），前台活跃时采用 15 秒轻量化静默轮询结合震动与轻提示音捕获新订单；商品管理采用标准品直接录入库存与多规格明细卡片直接调整库存的渐进式表单，并在类目删除时实行非空拦截校验，确保移动端操作轻便且不产生孤儿数据。
