# 商家工作台多端协同、极速退款与单页集成架构

为支撑小满食光实体门店高峰期多人协同出餐及高敏运营诉求，系统在小程序商家工作台落地以下架构决策：

1. **多微信号协同绑定（1-to-N Binding）**：
   支持店铺管理员账号（`xiaoman`）同时绑定多个店员微信（OpenID）。店长与出餐咖啡师可各自在移动端保持工作台登录，共享新订单提醒、并发出餐核销与小票补打，各设备支持独立安全解绑。

2. **移动端售后退款闭环**：
   在工作台订单流水直接开辟退款审核通道，店长可直接在手机端对未出餐申请执行「同意退款」（自动原路返还微信支付并作废未打单据）或「拒绝退款」，规避早高峰顾客退款时需登电脑后台造成的出餐延误。

3. **单页沉浸式工作台（Integrated Workbench）**：
   前端采用 `/pages/admin/workbench` 单页面分段式架构，聚合「订单流水」、「商品与类目」、「门店与硬件」三大核心 Tab，辅以悬浮扫码核销浮窗与轻量轮询调度器，极大减少多级页面路由跳转损耗，契合门店手持单手操作体验。
